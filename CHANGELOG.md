# Изменения

## 2.1.0 (не выпущено)

- Вернулся «Код для друга» (был в 1.0.0): панель → «Код для друга» → «Поделиться» кладёт код твоих настроек в буфер
  обмена; друг жмёт «Вставить код», видит, что изменится на его аккаунте, и записывает одной кнопкой (бэкап перед
  записью, «Отменить» сразу или позже в «Бэкапах»). В коде — бинды, чувствительность, активный прицел, HUD, миникарта,
  звук; без графики и без данных аккаунта. ~600 символов (только бинды — ~180). Коды 1.0.0 читаются.
- Ссылки `valset:code/<код>` и `valset:pro/<ник>` открывают панель с предпросмотром этого кода / примерки про;
  без нажатия кнопки в предпросмотре ничего не пишется.
- «Про»: нажатие на про сначала показывает, что изменится, примерка — кнопкой.
- «Скины» в панели: «Сохранить текущие как набор» — скины оружия (с цветом и уровнем), брелоки, спреи и флексы, карточка,
  титул, рамка уровня. Нажатие на набор показывает «было → станет» с названиями предметов, «Надеть» — бэкап и запись,
  «Отменить» — сразу. Только свои предметы: если Riot отказал — понятное сообщение, ничего не меняется.
- Набор можно привязать к агенту; переключатель «Менять скины при выборе агента» (выкл по умолчанию) надевает набор,
  когда фиксируешь агента, — без опроса, по событию клиента Riot. Надетый посреди матча — виден со следующего.
- Надёжность: запросы к Riot повторяются с растущей паузой (1-2-4-8 с, до ~20 с ожидания), пока жив токен входа;
  устаревший токен берётся у клиента заново. Пока идут повторы, панель пишет «Riot не отвечает — повтор N…».
- Наборы работают с лоадаутом Riot v3 (с 13.09 старый адрес отвечал 404 и «Сохранить набор» падал); наборы, сохранённые
  раньше, надеваются без брелоков — их стоит пересохранить.
- Команды ядра: `valset do loadoutsave:<имя> | loadout:<id> | loadoutbind:<id>:<агент> | loadoutdel:<id> | loadoutauto`,
  `valset list loadouts | agents | loadout:<id>`.
- Команды ядра: `valset do share`, `valset do code:<код>`, `valset list code:<код>`, `valset list pro:<ник>`.

## 2.0.0 (2026-10-25)

- Приложение в трее вместо консольного меню и сторожа: значок у часов (цвет — статус), панель с одной кнопкой по
  ситуации, уведомления с кнопками («Применить мои», «Сохранить», «Отменить»), значок у окна клиента Riot. Собирается
  на твоём ПК из исходника (src\app), запускается с Windows, выключается в настройках (config.app, config.badge).
- Всё в панели без консоли: «Что отличается», «Про», «Аккаунты», «Бэкапы», «История», «Настройки», «Справка».
  Ядро работает в памяти приложения: ответ панели без запуска PowerShell каждый раз.
- Установка: один файл и для новой установки, и для обновления; в конце открывается панель, консоль закрывается.
- Автозапуск — ярлык в «Автозагрузке» (запись в реестре Run Windows иногда молча пропускала).
- Ctrl+Alt+V и valset-open-1.exe убраны; консольное меню остаётся запасным: ярлык «VALSET» в Пуске, команда valset.
- Для приложения: `valset state` (одна строка JSON), `valset do <действие>` без вопросов с отменой последнего
  действия (last-action.json), `valset pros` / `valset more` — меню сразу на экране.

Из 1.3.0:

- Надёжность: запросы к облаку повторяются; при блокировке Cloudflare — понятная ошибка; запись сверяется целиком;
  если игра запущена, перенос ждёт её закрытия; файлы пишутся через временный — без риска порчи.
- Сессионный эталон: правки в игре на твоих аккаунтах сохраняются в «мои настройки» сами (после игры, при открытии
  меню или перед переносом). Примерки про — нет. Каждое обновление — точка в истории: откат через «Ещё» → «История».
- «Запомнить как мои» → «Сохранить»: нужно только в первый раз или чтобы взять настройки с другого аккаунта.
- Имена аккаунтов с кириллицей читаются правильно (старые чинятся при чтении).

## 1.2.0 (2026-10-11)

## 1.1.0 (2026-10-10)

- Графика не доходила до аккаунта, который ещё не играл на этом ПК: папка создавалась в угаданном регионе (-ap), а игра
  взяла другой (-eu). Теперь — заранее во все регионы этого ПК.
- Перенос падал после записи с ошибкой «Argument types do not match» (PowerShell 5.1, большой список отличий):
  настройки при этом записывались, но итог и вопрос про возврат исходных не показывались.

- Перенос на время: на аккаунте только твои прицелы (раньше — твой плюс прицелы аккаунта); его прицелы
  возвращаются вместе с исходными. Насовсем — как прежде.
- Главный экран — только то, что нужно этому аккаунту сейчас (обычно 1–3 пункта); остальное — в новом экране «Ещё».
  Уведомления, автоперенос, аккаунты, бэкапы («Откат аккаунта» и «История моих настроек» — один пункт) — там.
- Убрано то, что не про «мои настройки на любом аккаунте»: «Изменить» (редактор настроек без игры — их меняют
  в самой игре), несколько наборов, код для друга. Кода на 550 строк меньше.
- Заготовка «Настройки про» (примерить на время, чувствительность пересчитывается по DPI). Появится в «Ещё»,
  когда в списке будут про.
- Исходные возвращаются, даже если вышел из аккаунта прямо из игры (раньше — только при выходе на рабочий стол):
  помощник держит токен игры в памяти и берёт новый, когда клиент его обновляет. Не вышло — уведомление.

## 1.0.0 — первая публичная версия

- «Запомнить как мои» / «Перенести мои»: всё, только бинды, только графика; предпросмотр изменений перед записью.
- Главный экран: аккаунт по Riot ID, совпадают ли на нём твои настройки, курсор на нужном действии.
- «Изменить»: бинды, мышь, интерфейс, статистика на экране, графика — без игры.
- Прицелы аккаунта не стираются при переносе (лимит игры — 15).
- Графика одна на ПК: сама уходит во все аккаунты этого ПК; при запущенной игре — после выхода.
- Бэкап аккаунта перед каждой записью и «Откат аккаунта»; «История моих настроек» (10 версий).
- Наборы настроек и код для друга (VALSET2, ~175 символов только бинды).
- Помощник в фоне по желанию: уведомления и автоперенос, без опроса системы (события клиента Riot).
- Ctrl+Alt+V во время игры ничего не открывает.
- Первый запуск: приветствие и три шага; установка и обновление из скачанного файла; запасные пути, если Ctrl+Alt+V не сработал.
- Общий ПК: один раз спрашивает, писать графику во все аккаунты ПК или только в текущий («Аккаунты» → «Графика на этом ПК»).
- Windows 10 / 11: символы интерфейса только из шрифтов старой консоли.
- «На время» — стандарт: перенос на любой аккаунт, кроме основного, временный, исходные возвращаются через ~3 с
  после закрытия игры; «насовсем» и пометка «мой аккаунт» — без возврата.
- Интерфейс на русском и английском: выбирается сам по языкам Windows, переключается в справке (L).
- Установка одной командой (Win+R) без окна SmartScreen; описание на английском и русском.
