# Изменения

## 1.0.1

- Графика не доходила до аккаунта, который ещё не играл на этом ПК: папка создавалась в угаданном регионе (-ap), а игра
  взяла другой (-eu). Теперь — заранее во все регионы этого ПК.
- Перенос падал после записи с ошибкой «Argument types do not match» (PowerShell 5.1, большой список отличий):
  настройки при этом записывались, но итог и вопрос про возврат исходных не показывались.

- Перенос на время: на аккаунте только твои прицелы (раньше — твой плюс прицелы аккаунта); его прицелы
  возвращаются вместе с исходными. Насовсем — как прежде.

## 1.0.0 — первая публичная версия

- «Запомнить как мои» / «Перенести мои»: всё, только бинды, только графика; предпросмотр изменений перед записью.
- Главный экран: аккаунт по Riot ID, совпадают ли на нём твои настройки, курсор на нужном действии.
- «Изменить»: бинды, мышь, интерфейс, статистика на экране, графика — без игры.
- Прицелы аккаунта не стираются при переносе (лимит игры — 15).
- Графика одна на ПК: сама уходит во все аккаунты этого ПК; при запущенной игре — после выхода.
- Бэкап аккаунта перед каждой записью и «Откат аккаунта»; «История моих настроек» (10 версий).
- Наборы настроек и код для друга (VALSET2, ~175 символов только бинды).
- Помощник в фоне по желанию: уведомления и автоперенос, без опроса системы (события клиента Riot).
- Ctrl+Alt+V во время игры ничего не открывает.
- Первый запуск: приветствие и три шага; установка и обновление из скачанного файла; запасные пути, если Ctrl+Alt+V не сработал.
- Общий ПК: один раз спрашивает, писать графику во все аккаунты ПК или только в текущий («Аккаунты» → «Графика на этом ПК»).
- Windows 10 / 11: символы интерфейса только из шрифтов старой консоли.
- «На время» — стандарт: перенос на любой аккаунт, кроме основного, временный, исходные возвращаются через ~3 с
  после закрытия игры; «насовсем» и пометка «мой аккаунт» — без возврата.
- Интерфейс на русском и английском: выбирается сам по языкам Windows, переключается в справке (L).
- Установка одной командой (Win+R) без окна SmartScreen; описание на английском и русском.
